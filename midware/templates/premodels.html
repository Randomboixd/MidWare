Calling a premodel

Send the slug as the whole model value. Trailing text after the slug overrides the premodel's model, and a [Host] prefix still wins for routing.

{
  "model": "{{ premodel_prefix }}programming-model",
  "messages": [...]
}
  • {{ premodel_prefix }}slug → the premodel's connection and model.
  • Unknown slug → 404 unknown_premodel.

Premodels alias models, bind a system prompt, or accept a SillyTavern preset.
