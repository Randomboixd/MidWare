Calling a premodel

Send the slug as the whole model value. The trailing text after the slug overrides the premodel's model, and a [Host] prefix still wins for routing:

{
  "model": "<p>-programming-model",
  "messages": [...]
}
  • <p>-slug → the premodel's connection and model.
  • Unknown slug → 404 unknown_premodel.

Use for premodels

Premodels are essentially custom models built on top of api models! You can use it for aliasing models, or perhaps making a model with a custom system prompt (Sillytavern Presets accepted too!)
