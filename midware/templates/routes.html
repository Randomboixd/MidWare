Calling a specific host

Prefix the model with a route name in square brackets. MidWare strips the prefix and sends the rest upstream untouched, so you can leave your client's default route alone and still reach every other host.

{
  "model": "[NanoGPT]xiaomi/mimo-v2.5-pro:thinking",
  "messages": [...]
}
  • No prefix → the default route.
  • [Name] → that route, matched case-insensitively.
  • [#3] or [Name#3] → route by id, handy when names are ambiguous.
  • Unknown name → 404 unknown_host (traffic is never silently misrouted).

The model list

GET /v1/models returns MidWare's own catalogue rather than the upstream's, so one request covers every configured host. The default route's models are bare and every other route's are prefixed with [Name]:

{
  "object": "list",
  "data": [
    { "id": "gpt-4o-mini",            ... },   ← default route
    { "id": "[NanoGPT]xiaomi/mimo",   ... }    ← accepted verbatim
  ]
}

The catalogue is refreshed automatically when a route is added or edited, when the default route changes, and roughly once a day. Use Refresh models above to update it on demand.
